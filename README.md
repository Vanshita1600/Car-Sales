# Car Sales Management System

A console-based application developed in C to manage car inventory, customer purchases, sales records, and customer feedback.

## Features
- View available cars and stock.
- Process customer purchases and calculate costs.
- Apply membership discounts.
- Manage sales records and statistics.
- Collect and display customer feedback.
- Store data using file handling.
- Implement basic XOR encryption.

## Technologies
- C Programming
- File Handling
- Arrays and Functions
- Basic XOR Encryption

## Compilation and Execution

Compile using GCC:

```bash
gcc Car_Sales.c -o car_sales
```

Run the application:

```bash
./car_sales
```

On Windows, run `car_sales.exe`.

## Purpose

This project demonstrates fundamental C programming concepts through a car dealership management system.
